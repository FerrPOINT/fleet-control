# Политика безопасности

## Поддерживаемый статус

Реализованная версия работает в локальном контуре (umbrella-стенд, loopback-порты). Production-размещение не поддерживается; политика действует для репозитория и локальных развертываний.

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости в публичном issue, pull request, changelog или обсуждении. Сообщите владельцу репозитория через согласованный закрытый канал и приложите:

- краткое описание и затронутую область;
- воспроизводимые шаги или минимальный безопасный пример;
- возможное влияние;
- сведения о версии, ветке или ревизии.

Не включайте в сообщение рабочие токены, пароли, приватные ключи, персональные данные или полные дампы.

## Области повышенного внимания

- границы agents_root и изоляция runtime-каталогов агентов;
- runtime-token и JWKS-валидация, authZ на мутациях;
- редакция секретов в env/config при выдаче через API и в логах;
- исключение секретов из репозитория, логов и тестовых данных.
