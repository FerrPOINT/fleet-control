# Fleet Control Documentation

Fleet Control is the runtime fleet layer in the SDLC suite. It complements:

- `task-tracker`: task planning and issue lifecycle
- `project-workflow`: workflow phases, namespaces and supervisor gates
- `wiki`: documentation, evidence and knowledge base
- `CI-CD`: build and deployment pipelines
- `hermes` and `java-agent`: agent runtimes
